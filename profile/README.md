# RobotDen

**A skunkworks and community building open-source robotics — in the open, for everyone.**

Robotics development is concentrating inside private organizations. We think the flywheel belongs to the people: anyone should be able to bootstrap a robotics solution in their basement or launch a robotics company from a garage. RobotDen exists to lower that barrier — open software, open AI, open hardware.

## Projects

| Project | What it is | Status |
|---|---|---|
| [ganglion](https://github.com/RobotDen/ganglion) | Hostile-network reachability and sandboxed field tooling for ROS 2 robot fleets. Rust, libp2p, signed WASM capabilities. `cargo install gang` | usable — v1.0 on crates.io |

More is on the bench — the den ships continuously. Watch this org or join the list at [robotden.dev](https://robotden.dev).
